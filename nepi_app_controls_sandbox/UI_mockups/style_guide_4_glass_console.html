Style Guide 04

Glass Console

Frosted panels floating over a deep-space gradient, cyan/violet accent glow, and a "mission control at night" mood — for a fully dark operating environment where the interface itself should feel like an instrument panel, not a form.

Principle

Where Field Industrial optimizes for direct sun, this guide is its opposite: a night-operations or indoor-dark-room console, where a bright white UI would be actively harmful to an operator's vision. Panels are translucent "glass" layered over a soft gradient background so nothing is a flat rectangle; state changes are communicated with light — a glow, not just a color swap — because color alone reads poorly against a dark background at a glance. This is the highest- drama option of the five, aimed at making the sandbox demo feel like a spacecraft telemetry readout rather than a settings page.

Rules

— Every panel is translucent (6–10% white over the gradient) with a 1px hairline border at 14% white, never opaque.
— State changes are shown with a glow (box-shadow bloom in the accent hue), not just a fill/color swap, so they read at a glance in the dark.
— Cyan = informational / primary action; violet = selection/secondary; green = confirmed; red = danger, reserved exclusively.
— Background is a fixed radial-gradient "nebula," never plain — panels float over it, they never replace it with flat color.
— Numeric/live readouts may use a monospace accent color (green) to read as telemetry, distinct from static body text.
Glass Console covers the same 18 demo fields (10 controls + 8 data) as the real app. See concept_4_glass_console.html and UI_mockups/README.md for the full layout and rationale.
